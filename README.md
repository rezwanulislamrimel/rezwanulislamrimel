## 👋 About Me

I'm a detail-oriented **SQA Engineer** passionate about delivering high-quality, bug-free software. I specialise in bridging the gap between manual precision and automated efficiency — building scalable test frameworks, performance engineering pipelines, and CI/CD-integrated automation suites using modern industry-standard tooling.

- 🏢 **Currently:** Junior SQA Engineer at **unidevGO Software Solutions Ltd.** — ensuring top-tier quality across web and mobile applications
- ⚡ **Core Focus:** End-to-end automation with **Playwright (TypeScript)**, API testing with **Postman & Newman**, and performance engineering with **K6**
- 🔁 **DevOps:** Building hybrid CI/CD pipelines using **Jenkins + GitHub Actions** with **Ngrok webhook tunneling** and **Docker** containerization
- 🤝 **Open to Collaboration:** Web/mobile automation, performance testing, and QA process optimisation projects
- 💬 **Ask Me About:** Manual testing, test case design, bug reporting (Jira), API testing, web automation, SDLC/STLC
